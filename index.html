홈 화면에 설치하기

내 구글 캘린더에 셀 일정 띄우기

구글 계정에 '목자의 삶'이라는 캘린더를 하나 더 만들어, 이 앱의 일정을 거기에 넣는 방법이에요. 셀 일정만 따로 켜고 끌 수 있어서 개인 일정과 섞이지 않아요.

한 번만 — 캘린더 만들기

  1. 컴퓨터에서 calendar.google.com 접속
  2. 왼쪽 아래 다른 캘린더 옆 + → 새 캘린더 만들기
  3. 이름을 목자의 삶으로 적고 캘린더 만들기

방법 1 — 일정 하나씩 (가장 간편)

셀모임 입력 화면 아래 '구글 캘린더에 추가' 버튼을 누르면 구글 캘린더가 열려요. 저장하기 전에 위쪽에서 캘린더를 '목자의 삶'으로 바꿔주세요.

방법 2 — 한꺼번에 가져오기

  1. 캘린더 화면 아래 '전체 일정 내려받기'를 눌러 파일을 받아요 (.ics)
  2. 구글 캘린더 → 오른쪽 위 설정(톱니) → 가져오기 / 내보내기
  3. 받은 파일을 고르고, 캘린더 추가에서 목자의 삶을 선택 → 가져오기

새 일정을 넣은 뒤 다시 받아서 가져오면 돼요. 같은 일정은 덮어써지니 중복되지 않아요.

※ 앱이 구글 캘린더에 자동으로 써넣지는 않아요. 그러려면 구글 계정 권한을 따로 받아야 하는데, 지금 구조로는 어려워서 이 방법을 권해요.
